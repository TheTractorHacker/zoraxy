Requests matching any rule below skip the CAPTCHA challenge. Use a path (prefix such as /api, an exact path, or a regular expression matched against the whole path) for webhooks and APIs, or an IP / CIDR (e.g. 10.0.0.0/8) for trusted networks. No Exception Rule
Exact and regex rules only match requests whose path is already in canonical form (no .., //, ; or double encoding), so a crafted path is challenged instead of being let through. Regex rules must match the whole path. The rules apply to every CAPTCHA provider.
IP rules match the connecting client address as seen by Zoraxy (trusted proxy headers are honoured only where configured globally).
