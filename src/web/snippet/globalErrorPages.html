Default error pages

Used by every proxy rule that is set to "use the global default". A rule can override or switch this off in its own Error Pages, Static Responses, CORS & Bandwidth editor.

Also applies to errors Zoraxy generates itself (521 upstream unreachable, 404 DNS failure, 503 busy). Event streams, gRPC and WebSocket upgrades are never replaced. Login challenges (401) and CAPTCHA pages are produced before proxying and are not affected.
