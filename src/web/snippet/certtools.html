Install issued certificate for

Zoraxy can import certificates from a folder managed by certbot, acme.sh, cert-manager or a secrets mount. Start Zoraxy with -certs_dir /path/to/certs (and optionally -certs_dir_interval seconds). Supported layouts: fullchain.pem + privkey.pem (also in live/<name>/ and any sub folder), <name>.crt + <name>.key, tls.crt + tls.key.

Imported certificates are copies: the source files are never changed or deleted, a certificate whose key does not match is rejected, and Zoraxy will not try to renew them.

Command hook

Command hooks are disabled. They let an administrator make Zoraxy execute a program, so they are only available when Zoraxy was started with -allow_hook_commands.

The event is passed in environment variables: ZORAXY_EVENT, ZORAXY_DOMAINS, ZORAXY_SUBJECT, ZORAXY_EXPIRY, ZORAXY_DAYS_LEFT, ZORAXY_CA, ZORAXY_ERROR, ZORAXY_EVENT_JSON. 30 second timeout, output is logged (first 4 KB).
