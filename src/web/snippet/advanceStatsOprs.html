Collection Settings

When enabled, requests denied by Zoraxy (blacklist / whitelist / GeoIP access rules, exploit detection, rate limit and CAPTCHA challenges) are not counted in the statistics and traffic maps. This only affects statistics, blocking is not changed. Upstream errors are still counted. Applies to new requests only.
