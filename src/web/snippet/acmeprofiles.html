ACME Profiles & Defaults
Saved certificate authorities, reusable DNS credentials and the default key type

Default key type

RSA2048
Used for new certificates when no key type is picked. EC keys are smaller and faster; RSA is the most compatible. Existing certificates keep their key type on renewal.

Saved certificate authorities

Add a private ACME server, ZeroSSL or Google (External Account Binding) once and pick it when requesting certificates. Each CA keeps its own ACME account. The EAB key is never shown again after saving.

Saved DNS credentials

Create profiles from the certificate request dialog ("Save these credentials as a reusable profile"), or paste the provider credentials here as JSON. Secrets are stored in the system database like the per-certificate DNS credentials and are never shown again. The default profile is pre-selected when you pick a DNS challenge and is used when a certificate has no credentials of its own.
