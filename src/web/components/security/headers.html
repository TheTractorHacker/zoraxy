Header access rules

Require a request header (for example a secret set by your CDN or a client) on a proxy rule, otherwise deny, drop the connection or answer 404. All rules of a proxy rule must pass; a rule passes if any of its values matches, so you can rotate secrets by adding the new value, deploying it, then removing the old one. Secrets are compared in constant time, never logged and never shown again after saving (leave a secret field empty to keep the stored one). Off unless rules are added.
