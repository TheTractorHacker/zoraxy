Basic auth: shared credential lists and path scope

Create named credential lists once and assign them to several proxy rules (in addition to the rule's own users). Optionally limit basic auth to path prefixes such as /admin; everything else on that host is then served without basic auth. Passwords are stored as argon2id hashes and are never shown; leave a password empty to keep the stored one. Basic auth must be the selected authentication method of the proxy rule (HTTP Proxy tab, Authentication).
