Bot rules (User-Agent)

Block, challenge or only log requests by User-Agent. Managed lists plus your own rules; good bots (Googlebot, Bingbot ...) can be allowed and are verified by reverse DNS so a faked User-Agent is not trusted. A User-Agent is easy to fake: this stops lazy bots and scanners, not determined attackers. Challenge needs a CAPTCHA on the proxy rule (otherwise it blocks). The AI crawler list is the same list the exploit detector's "block AI crawlers" option uses. Disabled by default.
