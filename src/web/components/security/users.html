Admin accounts

Create additional accounts for the admin panel. admin accounts can change everything; viewer accounts are read-only (every change is refused, and configuration export, account management and the web terminal are closed). Changing a password, disabling, renaming or deleting an account ends its sessions. The last enabled admin cannot be removed, disabled or demoted. Forgot everything? Start Zoraxy once with -reset_ac.
