Automatic abuse banning

Counts abusive events per client IP (trusted-proxy aware) and bans repeat offenders for a limited, escalating time. Loopback, private ranges, trusted proxies, this server and the allow-list below are never banned unless you explicitly allow banning private ranges. Disabled by default.

Remote API (external tools)

Allows scripts or fail2ban actions to ban / unban IPs: curl -X POST -H "Authorization: Bearer TOKEN" -d "ip=203.0.113.9&seconds=3600" https://admin-host/api/abuse/remote/ban (also /unban, /list). Disabled until a token is generated; only a hash is stored.
