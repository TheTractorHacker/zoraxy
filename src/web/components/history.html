History

Every change made through the admin interface or the REST API is saved as a version that you can compare and go back to. Versions are stored encrypted on this server; secrets (keys, tokens, password hashes) are never shown in a comparison. Logs, statistics, accounts and API tokens are not part of the history.

Retention settings

Pruning keeps a version when it is among the newest N or younger than D days, then enforces the size cap from the oldest version on. The newest 5 versions and any version a pending restore needs are never removed.

Restore
Restoring the whole configuration replaces your current settings and restarts Zoraxy. A version of the current state is saved first, so you can go back. Type RESTORE to continue.
