Security rules

Decide what happens to a request: when it looks a certain way, then block it, redirect it, challenge it and more. New rules start in log-only mode, so you see what they would do before they act.

Quick-start templates

Each one opens the builder with the conditions filled in, in log-only mode. Complete the empty parts, test it and create it.

Request tester

Describe a request and see which rules would match it, in order, and what would happen. It only simulates: nothing is performed, counted or sent.
