Encrypted Client Hello (ECH)
Hide the requested host name (SNI) from network observers on the HTTPS listener

How it works
  1. Enable ECH and pick a public name: the generic outer name seen on the wire. Zoraxy must serve a valid certificate for it (an existing wildcard certificate covers it).
  2. Publish the ECHConfigList below as the ech= parameter of an HTTPS (type 65) DNS record on every host you want to protect.
  3. ECH only applies to TLS 1.3. Clients that never saw the DNS record, and TLS 1.2 clients, keep working without it.
  4. Rotation keeps the previous key decrypting for the retain window, so clients with a cached DNS answer are not rejected. Keep the retain window longer than your DNS TTL.
HTTP/3: ECH is accepted over QUIC with the bundled quic-go and Go version (covered by a test), but browsers decide per connection which protocol to use; the alpn in the HTTPS record controls that.
The HTTPS listener is not running in TLS mode, ECH has no effect until TLS is enabled.
Use a generic name that is not one of the protected hosts. A public name under the same domain hides the sub domain, not the domain.
Clients pad the hidden host name to this length. Use the longest host name you serve.
