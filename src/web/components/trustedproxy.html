What is trusted proxy gating?
Headers such as X-Forwarded-For can be forged by anyone. With gating on, Zoraxy only reads the real client IP from them when the connection comes from an address on this list; otherwise the header is ignored. Only add proxies you control or that are run by a service you trust, for example the published address ranges of your CDN.
