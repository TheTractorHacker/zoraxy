AI assistant

An optional helper that explains blocked requests, suggests rules and writes a plain-language security plan. It is off by default and uses your own API key or a model on your own network. It only proposes: it can never change anything. You apply every change yourself, through the same screens as always, after a confirmation that shows exactly what will change. Suggested rules always start in log-only mode.

What is sent to the model?
  • Only the fields shown in Preview what will be sent: rule ids, rule descriptions, method, host, path, counts, country codes and user agents.
  • Never sent: cookies, authorization or any other header values, request or response bodies, query parameter values, tokens, passwords, certificates.
  • IP addresses are replaced by stable labels such as ip-7f3a1c unless you allow real addresses below.
  • Log fields can be written by attackers, so the model is told they are data, not instructions, and its answer is checked strictly before you see it.
