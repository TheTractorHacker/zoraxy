Fleet

Central management of several Zoraxy nodes from one hub. The hub publishes versioned configuration for the scopes you choose; nodes pull it with their own credentials and keep everything else local. The hub can only publish configuration and ask a node to sync: it can never run commands on a node.

Make this node the hub

This Zoraxy becomes the management console. Its own configuration is the source that is published to the nodes. Keep proxy rules that use {{node.name}} style variables on the hub only if the hub does not proxy them itself.

Join a fleet

This node uses the legacy shared-secret cluster (Cluster / HA page). Switch it to standalone there before joining a fleet.

Managed by

Objects of the managed scopes are read-only here. Leaving keeps the current files as ordinary local configuration.
