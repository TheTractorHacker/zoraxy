Web Application Firewall

Central management of the WAF (Coraza + OWASP Core Rule Set). The global policy applies to every proxy rule that is set to Inherit; rules can instead pick a profile, a fixed mode, or keep their own custom configuration. The global policy is off by default, so nothing changes until you enable it.
