Forward Auth

Configuration settings for the Forward Auth provider.

The Forward Auth provider makes a subrequest to an authorization server that supports Forward Auth, then either:

  • Allows the request to flow through to the backend when the authorization server responds with a 200-299 status code.
  • Responds with the response from the authorization server.

Example authorization servers that support this:

  • Authelia
  • Authentik
  • OAuth2 Proxy

OAuth 2.0 / OpenID Connect providers

Any number of identity providers can be configured. Each proxy rule that uses the OAuth2 authentication method picks one in its Security tab; rules that pick none use the provider default.

Redirect (callback) URI to register at your identity provider, one per protected host: https://<protected-host>/internal/oauth2 for the provider default, https://<protected-host>/internal/oauth2/p/<provider-id> for every other provider (shown in the list below). Logout URL: the callback URI followed by /logout (clears the Zoraxy session and, if the provider supports it, ends the provider session too). Sessions are stored encrypted in the Zoraxy database and survive a restart; refresh tokens never leave the server.

Zoraxy Auth

Zoraxy Auth is a built-in SSO authentication system that allows you to manage users directly within Zoraxy.

Setup Instructions

To use Zoraxy Auth, you will need to configure the gateway settings below.

  1. Enable the Zoraxy Auth Gateway by toggling the switch below.
  2. Set up an HTTP proxy rule to forward the SSO domain to the Zoraxy Auth SSO port.
    e.g. auth.example.com → localhost:5489
  3. Configure the SSO Redirect URL in the settings below to point to the SSO domain.
    e.g. https://auth.example.com

Logout Instructions

If your site uses Zoraxy Auth for SSO, for better UX, add a hyperlink to the logout URL in your application's navigation or user menu.

  1. To logout from SSO, navigate to the SSO domain and append /logout to the URL.
    e.g. https://auth.example.com/logout
  2. Click the "Logout from All Services" button to end your session across all connected services.
