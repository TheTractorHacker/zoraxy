1 Install zrok

zrok was not found on this machine
  1. Download the release for this machine from github.com/openziti/zrok/releases (binary zrok for 1.x, zrok2 for 2.x).
  2. Put it on the PATH of the user running Zoraxy (for example /usr/local/bin), or enter its full path below. The file name must start with zrok.
  3. Press Check again. In a container the binary must exist inside the container.
Binary, command line generation and self-hosted endpoint

2 Enable the environment with your account token

Create a free account at zrok.io (or use your own zrok service), copy the account token, paste it here and press Enable. Zoraxy does not learn your account name from zrok: it only knows whether a token is stored and whether zrok enable succeeded.
Stored in conf/zrok/token (0600), never shown again and removed from logs. zrok only accepts the token as a command line argument of zrok enable, so it is visible in the process list for the few seconds that command runs.
