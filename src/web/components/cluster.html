Cluster / HA

Run two or more Zoraxy nodes behind a virtual IP or an external load balancer. A shared cluster secret makes visitor sessions (CAPTCHA, load balancer stickiness) valid on every node. A primary can push its proxy configuration to followers, which pull a signed, encrypted snapshot. Standalone nodes (the default) are unaffected.

Legacy shared-secret mode. This page configures the original primary/follower mirror, where every node knows one cluster secret. For central management of several nodes with per-node credentials, scoped config, groups, staged rollouts and rollback, use the Fleet page. Both modes keep working; a node uses one of them.

Cluster secret

Every node of a cluster needs the same secret (min. 32 characters). It is stored in conf/cluster.json (mode 0600) and never displayed again after it was generated. Changing it requires a restart of every node to take effect for session cookies.
