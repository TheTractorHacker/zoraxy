                    What is a fallback certificate?
                    
                
      
                
      A fallback certificate is used when the reverse proxy cannot find a matching certificate for the requested server name. If you are using Cloudflare full (strict) mode, you can also upload the Cloudflare origin certificate here and set it as the fallback.
