Split-horizon helper (off by default)

A tiny authoritative DNS server that answers A / AAAA (plus minimal NS / SOA) for the hostnames and aliases of your proxy rules, so LAN clients can resolve your public names straight to this proxy. It is not a general DNS server: every other name is answered REFUSED. Bind it to one specific LAN address (UDP and TCP, default port 5353; port 53 needs privileges). Wildcard rules such as *.example.com answer every matching name. Per client rate limiting, response size limits and a TCP connection cap are always on.

A specific IP address is required. Without a port, 5353 is used.
