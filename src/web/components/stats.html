                    What counts as blocked?

                    A request is listed here when Zoraxy itself refused it before it reached your server:

                    • access rules (blacklist, allow list, country rules) and automatic bans,
                    • rate limits, the WAF, the exploit detector and bot rules,
                    • header rules, path rules, CAPTCHA and country challenges,
                    • client certificate and allowed-peer checks, failed basic auth or SSO, and plugins that refuse a request.

                    Errors returned by your own server (404, 500 ...) are not blocks. The list keeps the last 2000 blocked requests; the counters on the Status page keep counting beyond that. Query strings are not stored unless Visitors is set to keep them, requests from the statistics exclusion list are not recorded, and rules that opted out of statistics are skipped.

                    Recording is switched off. New blocked requests are not added to this list; it shows what was kept before. Switch it on again with "Record blocked requests" below.
