    Response protection

    Looks for leaked errors and secrets in what the server sends back. Saved with its own button.

    Looks for stack traces, database errors, secrets, directory listings and server banners in what this upstream sends back. Each group can follow the global setting (Inherit) or be overridden for this rule. Block replaces the response with a generic 502 page, but only when the leak is inside the first part of the body (the inspection window); Log only never changes the response. Streams, chunked responses of unknown length, partial content and non-text content are never held back or inspected. Block and Strip need the WAF of this rule in Block mode.

    API protection

    Limits and allow-lists for JSON, XML and form requests. Saved with its own button.

    Structural limits for JSON, XML and form bodies, a method / content type allow-list per path and optional OpenAPI 3 validation. Independent of the WAF source above; violations appear in the events below and on the WAF page.
