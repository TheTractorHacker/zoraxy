## Still open (not fixed here)

- `mod/update` migrations (`RunConfigUpdate`, v308..v335) hard-code `./conf/...`, so with a custom `-conf` the version file and config migrations act on the wrong folder (size M: thread a conf dir through 6 packages).
- `mod/tlscert` (`./tmp/localhost.pem`), `tlscert/handler.go` (`./tmp/download`) and `webssh.go` (`./tmp/gotty`) hard-code `./tmp` instead of `-tmp` (size S, harmless: directories are created on demand).
- #458 Infomaniak + punycode and #1067-style provider quirks need a real account.
- #1087 UX gap: reserved zones (CarrierNAT, Private, Loopback...) are not explained in the access rule UI (size S).
- #816 / second reporter: unexplained memory growth without auth; needs a long-running profile (pprof) on the reporter's workload.
