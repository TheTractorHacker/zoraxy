## Code and UI changes made

* `d8d88d0` WebSocket through a virtual directory keeps the base path of the target (Odoo #314, CleanSlate #622).
* `c5d4047` Longest matching virtual directory wins, independent of creation order (#417).
* `3936702` Empty DNS provider fields no longer overwrite provider defaults (PowerDNS #681).
* `9d83c82` Reason for an upstream failure (521/404) is logged, rate limited (#1102).
* `89dc754` Error page templates show the requested host/path for Zoraxy generated errors (#1095/#1102).
* `54c8ce4` Go profiling endpoints below `/api/info/pprof/` (#770).
* `9f335a3` Access page help: which address is checked, CGNAT/reserved ranges, trusted proxy gating (#1087).
